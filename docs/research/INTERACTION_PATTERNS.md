# Interaction Patterns

- **Navigation:** click-driven anchor navigation; mobile menu uses a button and full-screen overlay.
- **Hero:** static layered composition with a subtle image entrance.
- **Scroll reveals:** viewport-driven opacity and vertical translation.
- **Impact cards:** hover-driven transform and accent border.
- **Buttons:** hover-driven lift, focus-visible outline, and arrow translation.
- **Marquee:** time-driven horizontal loop with a duplicated content track.
- **Accessibility:** semantic landmarks, visible focus, large touch targets, descriptive links, and reduced-motion support.
