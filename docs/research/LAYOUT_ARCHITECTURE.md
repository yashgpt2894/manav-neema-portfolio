# Layout Architecture

## Desktop

- Maximum content width: `1680px`
- Fixed navigation with page gutters
- Hero height: minimum viewport height, central portrait card, background wordmark
- Most sections use 12-column CSS grids
- Journey rows use a 2/3/7 editorial split
- Impact uses one feature card plus two supporting cards
- Capability and education sections use 3-column grids

## Tablet

- Navigation hides secondary links.
- Hero becomes a two-column layout.
- Journey collapses to a year rail plus content.
- Impact and education become two columns.

## Mobile

- 390px reference target with `1.25rem` gutters
- Compact fixed header and full-screen menu
- Hero is a single vertical composition
- Floating capability cards remain layered but use smaller type
- All major grids collapse to one column
- CTAs stretch to comfortable touch targets

## Breakpoints

- Mobile: below `720px`
- Tablet: `720px` to `1023px`
- Desktop: `1024px` and above
