# Technical Stack Analysis

## Reference

- Webflow-generated site
- Custom fonts
- Fixed layered header/hero
- Motion-heavy scroll presentation

## Local equivalent

- Next.js 16 App Router and React 19
- Server components for static portfolio content
- Small client components only for mobile navigation and reveal observation
- Tailwind CSS v4 plus a focused global design layer
- `next/image` for responsive local image optimization
- `next/font/google` for self-hosted typography
- Lucide icons for lightweight interface symbols
- CSS transitions and IntersectionObserver instead of a large animation dependency
